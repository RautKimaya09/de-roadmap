# de-roadmap
## Day 1 notes
- pwd -> shows current directory
- ls -> gives details/list
- cd -> changes directory
- cp -> copies folder
- mv -> moves/renames folder
- rm -> removes folder

## Day 2 notes
- grep: print lines that contains text
- sort | uniq -c: sorts lines, then counts the duplicates
- wc -l: counts lines
- > overwrites a file, >> adds to the end of it
- | adds one command's output as input to the next
